write exactly one single-line joke about office life.

## How it works

`main.py` (Python 3, stdlib only, no input, no network) writes one joke to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`):

> The printer only jams when the document is urgent, which is how I know it reads the subject line.

The joke turns on a real office detail (the printer that jams at the worst
moment) and lands the laugh in the last few words. It is 97 characters on a
single line, inside the gate's 1–199 character limit.

## Run

```sh
python3 main.py
```
